About the recordings

The terminal recordings in casts/ are plain JSON files (casts/ask.json, wake.json, monitor.json, msg.json). They were made by running the real rakitsu binary against a tiny fake model server on the local machine. No API key, no private host and no home path is in them. The player is about 60 lines of JavaScript in each page. Waits are shortened; output is not edited. README explains how to regenerate everything.
