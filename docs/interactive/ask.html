rakitsu-ask

A native Claude Code subagent asks a rakitsu chat session a question, gets the reply back as fenced, untrusted text, and keeps the same conversation next time. The client is one Python file with no dependencies.

Source of the facts: scripts/rakitsu-ask and docs/native-subagent-bridge.md (from the native bridge change). The step diagram is explanation, diagram; the terminal recording further down is the real script against a real local rakitsu serve with a fake model, real run.
